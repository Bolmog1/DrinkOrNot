# DrinkOrNot
> Partagez vos recettes de cocktail et découvrez votre prochaine boisson préférée !
---
## Installation
```shell
git clone https://github.com/Bolmog1/DrinkOrNot/
cd DrinkOrNot
python -m venv .
source bin/activate
pip install -r requirements.txt
```

## Run
```shell
# Linux/MacOS
source bin/activate
flask --app main run
# Windows
./bin/activate.bat
flask --app main run
```
